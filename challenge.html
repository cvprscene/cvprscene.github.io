Challenge

This year we establish three challenges on multi-modal understanding and reasoning in 3D scenes:

  • Situated QA (SQA)

    Featuring SQA3D benchmark, answer a question given a scene and a sentence that describe the situation of an agent in that scene. You may use the ground truth location in this task.
    1. Overview: Please refer to this slide for an overview and this technical report for more details.
    2. Challenge Data: The participants are provided with training, validation (questions & answers) and testing set (questions). Follow this instruction for data organization. A codebase with baseline models is also available.
    3. Contact: For any additional questions regarding the SQA challenge, please contact Baoxiong Jia.

  • Multi-modal Situated QA (MSQA)

    Featuring MSQA, answer the question given interleaved text, image, and point cloud for situation and question.
